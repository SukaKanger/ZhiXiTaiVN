## 第 1 期 · 工作台：左边工程库，右边打包台（约 60 秒）

**标题**
手机上写视觉小说，左边挑工程右边直接出 APK

**口播**
我和 AI 协作开发了一款 Android 手机能用的开源视觉小说开发引擎，支持手机打包 APK。
这期只看界面。左边工程库，每个工程写着场景数、文件数、体积，点预览就能玩。

两栏都能收：点顶栏那个「打包台：右」的胶囊，或者拖中间那根竖缝。
收起来只剩一条细边，再点一下细边就还原，宽度还记得。
源码在 GitHub，详情看主页。

## 第 3 期 · 不会就问：内置 API 直接改剧本（约 75 秒）

**标题**
不会写剧本？把想法丢进去，它给你改成 WebGAL 台词

**口播**
我和 AI 协作开发了一款 Android 手机能用的开源视觉小说开发引擎，支持手机打包 APK。
右下角那个「问」，点开就是内置 API 面板。
把你想要的剧情一句话写进去，选模型、填自己的 Key，它按 WebGAL 语法回你一段能直接粘的台词。
不满意就再问一次，改到顺眼为止；粘进剧本编辑，预览立刻能看到。
源码在 GitHub，详情看主页。

## 第 4 期 · 端上打包：填个包名，APK 就出来了（约 100 秒）

**标题**
包名一填，手机上直接吐出一个能装的 APK

**口播**
我和 AI 协作开发了一款 Android 手机能用的开源视觉小说开发引擎，支持手机打包 APK。
最后一期看打包台。工程选进来，应用名、包名填好，图标点「选图片」，签名先用内置调试。
点「生成构建工程」，再点「开始构建」，右边日志一行行走，十几秒就出包。
产物在构建目录的 out 里，文件名带着你的包名，点安装就能装。
要发布就换自己的 keystore，调试签名只能自己测装。
源码在 GitHub，详情看主页。

**话题**
#视觉小说 #游戏开发 #安卓开发 #独立游戏 #WebGAL #开源 #手机打包APK

**置顶评论**
包名只能小写字母、数字和点，开头必须是字母；填错构建会直接报给你看。
