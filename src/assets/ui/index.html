三步把环境装好（只做一次）

  1. 给「所有文件访问」权限。
  2. 复制环境安装命令，切到 Termux 粘贴并按回车，把打包工具装好。
  3. 回来点「运行自检」，全绿就能打包。别把 Termux 丢后台——国产 ROM 会冻它。

自检红了怎么办

aapt2 跑不起来 / curl 报符号缺失：Termux 里装一下 libc++ 和 openssl，再重跑自检。

android.jar 不在：把 android.jar 放到 ~/.webgal-station/android.jar，或在 Termux 里联网重跑环境安装命令。

构建卡在 javac 不动：Termux 被系统冻了。把 Termux 打开放前台，或在工作站里关掉电池优化/后台限制后再点开始构建。

不会就问 没配过就是空的

只放行 https；本机回环（127.0.0.1 / localhost）例外，可以用 http。 Key 只写进本机偏好，不进日志、不进构建产物、不随工程导出。

打包参数都是啥？

    

    

      
应用名：装到手机桌面后显示的名字。中文、空格、emoji 都能用，别超过 20 个字。

      
包名：安卓给每个 App 的唯一身份证，格式像 com.你的名字.游戏名。只能小写字母、数字、点，开头必须是字母。同一个包名不能装两份，改包名相当于另一个 App。

      
版本名：给玩家看的版本，比如 1.1.6 或 1.1.7-beta。随便起，但别乱跳。

      
版本号：安卓用来判断“新旧”的整数，只能往上加。装新版时系统只认它，不认版本名。重复打包会自动 +1；手改后记得别再改回去。

      
游戏画面方向：锁死产物 APK 打开时的方向。视觉小说一般横屏；竖屏适合手机单手握；跟随系统让玩家自己转。

      
图标：桌面图标，选 PNG 最稳，别用带透明边的大图。不选就用默认图标。

      
来路角标：打开游戏先显示 3 秒“由织戏台打包”，方便玩家知道哪来的。不想露就别勾。

      
签名方式：调试签名能装能测，不能上架应用商店；「我的 keystore」用你已有的密钥；「新建 keystore」在本机生成一份属于你的，生成后备份好，以后一直用它，丢了就不能覆盖升级。

      
库口令 / 密钥口令：打开 keystore 的密码。留空会落到默认 android，只适合自测；要发布必须填自己的并备份。

      
生成构建工程：把工程、引擎、图标、签名参数拼到手机里的构建目录，不联网。

      
开始构建：让 Termux 在本机真正打 APK。第一次要先把离线工具链配好；打完会在下方给出 APK 的完整路径。
